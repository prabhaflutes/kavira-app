# Kavira — Literature App

This is a native Android Jetpack Compose starter for the Hindi-first literary platform.

Firebase configuration:
- The supplied `google-services.json` should be copied into `app/google-services.json`.
- The project is configured for the Android package from the supplied Firebase configuration.

The UI intentionally uses a dark, card-based, left-navigation style inspired by the supplied reference screenshot while adapting it to the literature application.

Next production steps:
1. Enable Firebase Authentication providers.
2. Create Firestore database.
3. Create Storage bucket.
4. Add Firestore and Storage security rules.
5. Replace sample content with Firebase repositories.
6. Add real authentication and profile setup.
7. Implement posts, drafts, comments, follows, messaging and publication submissions.
